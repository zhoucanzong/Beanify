## 1. 拼豆板尺寸标准

### 1.1 各品牌拼豆板尺寸

拼豆板（Pegboard）是拼豆制作的核心工具，各品牌的拼豆板在孔距上遵循5mm标准（对应5mm Midi拼豆），但具体尺寸和编码系统各有不同。

#### 常见单板尺寸

| 尺寸（钉数） | 总容量 | 用途 | 难度等级 |
|-------------|--------|------|---------|
| 11x11 | 121粒 | 小图标、耳环、表情符号 | 极简 |
| 15x15 | 225粒 | 新手练习、小型挂件、快速手工 | 简单 |
| 20x20 | 400粒 | 简单动物、基础字母、小型图案 | 中等 |
| **29x29** | **841粒** | **复杂设计、肖像、地图、详细场景（最常用）** | **进阶** |
| **30x30** | **900粒** | **国产常用标准、大型角色设计** | **进阶** |
| 36x36 | 1,296粒 | 大型墙饰、协作项目、展览级作品 | 专家 |
| 42x31 | 1,302粒 | 中型长方形作品 | 专家 |
| 64x47 | 3,008粒 | 大型长方形作品 | 专家 |

#### 长方形拼豆板

| 尺寸（钉数） | 总容量 | 适用场景 |
|-------------|--------|---------|
| 14x29 | 406粒 | Perler长方形板、角色半身像 |
| 29x15 | 435粒 | 小型长方形作品 |
| 30x59 | 1,770粒 | 超大型长方形、姓名墙饰 |

#### Perler品牌拼豆板物理尺寸

| 类型 | 钉数 | 物理尺寸（约） |
|------|------|---------------|
| 小型方形板 | 15x15 | 约7.5cm x 7.5cm |
| 标准方形板 | 29x29 | 约14.5cm x 14.5cm（5.7" x 5.7"） |
| 大型透明板 | 约41x55 | 约25.4cm x 33.7cm（10" x 13.25"） |

### 1.2 多板拼接尺寸

拼豆板之间可通过卡扣/连接件拼接，形成更大的工作区域：

| 拼接方式 | 总尺寸 | 总容量 | 建议场景 |
|---------|--------|--------|---------|
| 2x2拼接 | 58x58 | 3,364粒 | 大型角色全身像 |
| 3x3拼接 | 87x87 | 7,569粒 | 超大型马赛克墙饰 |
| 2x1拼接 | 58x29 | 1,682粒 | 宽幅场景画 |
| 4x4拼接 | 116x116 | 13,456粒 | 巨型展览作品 |

> **实践建议**：多板拼接时，每块板之间通常有1钉的重叠或间隙，实际拼接后尺寸可能略有减少。

### 1.3 按作品大小推荐尺寸

| 作品类型 | 推荐网格宽度 | 制作时间 | 适合人群 |
|---------|-------------|---------|---------|
| 挂件/钥匙扣 | 15-25 | 30分钟-1小时 | 新手 |
| 杯垫/冰箱贴 | 29-40 | 1-2小时 | 新手/进阶 |
| 游戏角色/宠物 | 41-58 | 2-4小时 | 进阶 |
| 肖像/动漫人物 | 59-80 | 4-8小时 | 进阶/高级 |
| 大型墙饰 | 80-120 | 8小时以上 | 高级 |

## 2. 颜色数建议

### 2.1 按作品类型推荐

颜色数量是影响图纸清晰度和制作复杂度的最关键因素。

| 作品类型 | 推荐颜色数 | 说明 |
|---------|-----------|------|
| 图标、标志、简单动物 | 12-18色 | 远看容易识别，色块清晰 |
| 游戏角色、吉祥物 | 20-30色 | 足够的层次和细节 |
| 肖像、复杂场景 | 30-45色 | 渐变过渡和肤色还原 |
| 极简/美学风格 | 5-8色 | 马卡龙色板，设计感强 |
| 像素艺术标志 | 12-20色 | 色少更干净 |

### 2.2 按玩家水平推荐

| 玩家等级 | 建议最大颜色数 | 理由 |
|---------|---------------|------|
| 完全新手 | 8-15色 | 减少混淆，降低备料难度 |
| 初级玩家 | 12-20色 | 逐步增加复杂度 |
| 进阶玩家 | 20-32色 | 能处理更多层次和渐变 |
| 高级玩家 | 32-50色 | 追求精细还原和照片级效果 |
| 专业玩家 | 50色以上 | 大型马赛克、照片级写实 |

### 2.3 颜色数限制最佳实践

- **最佳效果区间**：8-15色（新手友好，成品清晰度高）
- **色数过多的问题**：制作时容易混淆相似色、需要更大的拼豆库存、图纸可能显得杂乱
- **减少颜色数的方法**：
  - 先降噪再手动修改，合并相近颜色
  - 出现少于5格的颜色可手动替换为已有相近色
  - 使用"颜色整理"功能合并近似色
  - 设定色数上限进行自动限制

## 3. 图纸内容规范

### 3.1 必须包含的信息

一份完整的拼豆图纸应至少包含以下内容：

1. **网格区域**：按实际拼豆尺寸排列的方格矩阵
2. **颜色填充**：每个格子显示对应的拼豆颜色
3. **色号标注**：每个颜色对应的色号（品牌特定编码）
4. **用量统计**：按颜色统计所需拼豆数量
5. **作品尺寸**：总宽度x高度的网格标注

### 3.2 推荐包含的信息

- **坐标轴标注**：行列编号（建议每隔5或10格显示）
- **网格线**：基础网格线+每隔10格的加重分隔线
- **色标图例**：颜色-色号对照表
- **辅助信息**：作品名称、作者、制作日期
- **品牌标识**：适用的拼豆品牌
- **预计包数**：按包装规格计算购买量

### 3.3 标注方式

#### 色号显示方式

| 方式 | 适用场景 | 优缺点 |
|------|---------|--------|
| 格子内显示色号 | 打印图纸对照摆放 | 直观但可能遮挡小格子 |
| 图例对照方式 | 颜色差异大的图纸 | 图纸更简洁但需要查表 |
| 鼠标悬停/数字标注 | 电子图纸 | 不占用格子空间 |

**推荐做法**：提供"显示/隐藏色号"选项让用户自选。对于打印版，建议同时提供带色号和不带色号两个版本。

#### 坐标标注规范

- 每隔10格显示坐标编号（如10, 20, 30...）
- 列坐标使用数字（1, 2, 3...）或字母（A, B, C...）
- 行坐标使用数字（1, 2, 3...）
- 坐标标注位于网格边缘，不占用主图纸区域

### 3.4 打印规范

| 项目 | 推荐标准 |
|------|---------|
| 纸张尺寸 | A4（横向）或 US Letter（8.5" x 11"） |
| 打印设置 | 选择"实际尺寸/Actual Size"，不要自适应缩放 |
| 每格尺寸 | 打印后每格约1.8-2.0mm（A4横向29x29约可完整打印） |
| 网格缩放 | PNG导出建议2x缩放保证清晰度 |
| 大图纸处理 | 超A4范围的图纸可分页打印或缩小整体比例 |

## 4. 拼豆规格与品牌色号

### 4.1 拼豆物理规格

| 规格 | 直径 | 适用板 | 特点 |
|------|------|--------|------|
| Maxi/大号 | 8-10mm | 专用大孔板 | 适合幼儿，防误吞 |
| **Midi/标准** | **5mm** | **标准拼豆板（5mm孔距）** | **最常用规格，适合所有人群** |
| Mini/小号 | 2.5-2.6mm | 专用小孔板 | 精细作品，适合进阶玩家 |

**5mm Midi拼豆物理参数**：
- 直径：5.0mm
- 理想拼豆板孔距（中心到中心）：约6.0-6.3mm
- 单粒重量：约0.01g（估算，1000粒约10g）
- 材质：聚乙烯（PE），加热后熔合
- 熨烫温度：中温（约150-160°C / 300°F）

### 4.2 各品牌色号系统

| 品牌 | 产地 | 色号编码 | 颜色数量 | 特点 |
|------|------|---------|---------|------|
| Perler | 美国 | 数字编码（如019） | 102-221色 | 入门友好，北美常见 |
| Hama | 丹麦 | H编码（如H22） | 92色 | 品质稳定，欧洲经典 |
| Artkal S-5mm | 中国 | S编码（如S14） | 199色 | 颜色最多，性价比高 |
| MARD（国产） | 中国 | 系列字母+编号（如A1, B10） | 221-291色 | 国内最常用，色号系统完善 |
| Nabbi | 瑞典 | 数字编码 | 23-30色 | 环保生物塑料，北欧风 |
| Yant | 中国 | 数字编码 | 119色 | 文艺清新，莫兰迪色调 |

> **重要**：各品牌色号系统不通用，相似颜色的RGB值可能存在差异。图纸工具应支持按品牌切换色号和色板。

### 4.3 国产拼豆常用色号体系

国产拼豆普遍采用MARD兼容色号体系，按字母分系列：

| 系列 | 颜色类型 | 色数 |
|------|---------|------|
| A系列 | 黄色/橙色 | 26色 |
| B系列 | 绿色系 | 32色 |
| C系列 | 多彩/基础色 | 多色 |
| D系列 | 蓝色系 | 多色 |
| E系列 | 粉色系 | 24色 |
| F系列 | 红色系 | 25色 |
| G系列 | 棕色系 | 多色 |
| H系列 | 灰色/黑白 | 多色 |
| M系列 | 浅色/白色 | 多色 |
| P/Q/R/T/Y/ZG系列 | 特殊效果（珠光/温变/荧光等） | 多色 |

## 5. 材料统计规范

### 5.1 统计维度

材料统计应包含以下维度：

1. **按颜色统计**：每种颜色的使用颗粒数
2. **按系列统计**（可选）：按品牌系列分组
3. **预计包数**：根据包装规格换算
4. **总计**：作品总颗粒数

### 5.2 统计表格格式

| 列名 | 说明 |
|------|------|
| 序号 | 编号 |
| 色号 | 品牌对应的色号编码 |
| 颜色预览 | 颜色样本/色块 |
| 颜色名称 | 可选，如"红色""肤色" |
| 使用颗粒数 | 该颜色的总用量 |
| 每包数量 | 包装规格（用户可设置） |
| 建议购买包数 | 颗粒数/每包数量（向上取整） |
| 建议购买量（含余量） | 增加20%备用 |

### 5.3 包装规格

#### 常见包装方式

| 包装类型 | 规格 | 适用场景 |
|---------|------|---------|
| 单色小包装 | 100粒/包 | 少用量颜色补充 |
| 单色标准包 | 500粒/包 | 中等用量 |
| **单色标准包** | **1000粒/包** | **最常用规格** |
| 单色大包装 | 2000-5000粒/包 | 大量使用的颜色（黑、白、肤色） |
| 混色大包 | 3000-10000粒 | 入门试玩 |
| 按克数售卖 | 10g/50g/100g/200g/500g | 散装称重 |

> **重量参考**：2.6mm小豆约1000粒/10g，5mm大豆约1000粒/20-25g

#### 购买建议

- 建议购买量 = 实际用量 x 1.2（20%余量）
- 常用色（黑、白、肤色）可多备1-2包
- 每色每图案通常需50-200粒，主导色可能需300粒以上
- 设置默认每包数量：1000粒（用户可自定义）

## 6. Excel图纸格式标准

### 6.1 布局建议

拼豆Excel图纸建议包含三个工作表：

#### 表1：主图页（图纸区域）

| 设计要素 | 规范 |
|---------|------|
| 单元格形状 | 正方形（行高列宽一致） |
| 颜色表示 | 单元格背景色（Fill Color） |
| 色号标签 | 单元格内文字（可选显示/隐藏） |
| 网格线 | Excel默认网格线即可 |
| 分隔线 | 每隔10行/列加粗边框表示分区 |
| 行列坐标 | 顶部和左侧标注行号列号 |
| 冻结窗格 | 冻结首行首列方便滚动查看 |

#### 表2：配色索引页

| 列 | 内容 |
|----|------|
| A | 序号 |
| B | 色号 |
| C | RGB值 |
| D | 品牌编码 |
| E | 使用频次（颗粒数） |
| F | 使用占比 |
| G | 颜色预览块 |

#### 表3：坐标定位页（可选）

按行列列出每个位置的颜色编号，方便核对：

```
    A   B   C   D   ...
1   A1  A1  B5  ...
2   A1  F3  B5  ...
3   ...
```

### 6.2 颜色表示方式

| 方式 | 说明 | 推荐度 |
|------|------|--------|
| **单元格背景色** | 最直观的表示方式，直接对应拼豆颜色 | ★★★★★ |
| 单元格内色号文字 | 显示色号编码，便于查对 | ★★★★☆ |
| 单元格内数字序号 | 使用简化编号（1, 2, 3...） | ★★★☆☆ |
| 条件格式标注 | 使用Excel条件格式突出显示 | ★★☆☆☆ |

**最佳实践**：单元格背景色表示实际颜色 + 小字号显示色号文字

### 6.3 标签规范

- **色号位置**：优先显示在单元格内（居中），字号尽可能小
- **字体颜色**：根据背景色亮度自动选择黑/白字体（对比度>4.5:1）
- **字体大小**：建议6-8pt（视格子大小调整）
- **色号格式**：显示品牌原始编码（如A1、F03、H22等）
- **隐藏选项**：提供"仅颜色"和"颜色+色号"两种模式

### 6.4 打印适配

- 设置打印区域为图纸区域+图例
- 调整列宽行高使单元格为正方形
- 打印时勾选"打印网格线"
- 对于大图（>50x50），考虑分页符设置
- 建议单色打印时确保色号文字清晰可读

## 7. 图纸导出规范

### 7.1 支持的导出格式

| 格式 | 用途 | 特点 |
|------|------|------|
| PNG高清图 | 打印/分享 | 带网格线和色标图例，适合打印后对照摆豆 |
| PDF矢量图 | 打印/存档 | 缩放不失真，支持添加页眉/页脚 |
| CSV表格 | 数据处理 | 按行列列出每个格子的颜色编号 |
| Excel (.xlsx) | 统计/教学 | 多表结构，包含主图+索引+统计 |
| JSON | 数据交换 | 供开发者调用或导入其他App |

### 7.2 导出选项

建议提供以下可配置选项：

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 显示网格线 | true | 基础网格线的显示/隐藏 |
| 网格间隔 | 10 | 加重分隔线的间隔（格数） |
| 显示坐标 | true | 行列编号的显示/隐藏 |
| 显示色号 | true | 单元格内色号的显示/隐藏 |
| 包含统计 | true | 底部是否包含用量清单 |
| 按画布尺寸/图案尺寸导出 | 图案尺寸 | 是否包含空白边缘 |
| 包含背面参考图 | false | 生成镜像版本（适合双面作品） |

### 7.3 图层支持（进阶）

复杂作品可能需要多图层功能：

- 每个图层独立编辑和导出
- 可选择图层是否计入用量统计
- 支持图层显示/隐藏、锁定、合并
- 多层作品按图层分别导出图纸

## 8. 图案设计最佳实践

### 8.1 最小色块处理

- **孤立单豆**：单个孤立的拼豆在熨烫时容易脱落，建议：
  - 自动清理绝对孤立点（8邻域最多1个同色邻居）
  - 或将其合并到最近的相近色区域
- **2x2小色块**：眼睛细节等关键2x2色块应保留
- **噪点清理**：使用自适应降噪，根据总颗粒数分4级强度

### 8.2 制作前检查清单

- [ ] 缩略图状态还能看清主体吗？
- [ ] 关键边缘不用放大也清楚吗？
- [ ] 最暗和最亮的颜色是否有冲突感？
- [ ] 颜色数量是否符合库存？
- [ ] 是否有过多的孤立单豆？
- [ ] 是否做过小区域试拼？

### 8.3 肤色处理建议

- 选一个中间色、一个阴影色、一个高光色
- 高光不要用纯白，浅米色或淡桃色更自然
- 肤色偏红或偏黄时调整中间色，保持阴影偏中性
- 重点放在眼睛和嘴唇的刻画上

## 9. 推荐默认值

| 配置项 | 推荐默认值 | 理由 |
|--------|-----------|------|
| **默认画布尺寸** | **29x29** | 最通用的标准拼豆板尺寸，Perler主流规格 |

| **默认拼豆规格** | **2.6mm（小豆）** | 国内主流选择，精度更高 |
| **默认每包数量** | **1000粒** | 市场最常见的包装规格 |

| **默认网格间隔** | **10格** | 与拼豆板分区线对齐 |
| **默认导出格式** | **PNG + Excel** | PNG打印对照 + Excel统计采购 |
| **图纸打印尺寸** | **A4横向** | 通用打印标准 |
| **单品牌/多品牌统计** | **单品牌统计** | 按选定品牌统一色号，便于采购 |
