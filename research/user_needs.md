# 拼豆图纸生成工具用户需求分析

> 调研时间：2025年7月  
> 数据来源：小红书、B站、贴吧、GitHub、电商平台、行业报告、用户评论等  
> 调研范围：国内外拼豆用户群体

---

## 1. 用户画像

### 1.1 主要用户群体

根据艾媒咨询《2026年中国"拼豆"行业发展状况与消费行为调查数据》，拼豆消费者呈现以下特征：

**性别分布：**
- 女性用户占 **77.78%**，是绝对主力消费群体
- 男性用户占 22.22%，多为游戏/动漫/科技爱好者

**年龄分布：**
- Z世代（18-25岁）与千禧一代（26-35岁）合计占比 **超过90%**
- 18-24岁为核心活跃群体（B站用户中18-24岁占60.28%）
- 35-44岁占比约21%，主要为亲子家庭消费群体
- 45岁以上占比15%，偏好实用型消费

**职业分布：**
- 上班族和自由职业者为消费主力，合计占比 **93.41%**
- 学生群体是重要增量群体，假期消费明显增长
- 亲子家庭（父母+孩子）占比约8%

**收入分布：**
- 中高收入群体（月收入5001-15000元）占比突出
- 客单价集中在 51-100元区间
- 消费频次以每月1次及以上为主

**地域分布：**
- 核心人群集中在二线与新一线城市，合计占比 **70.99%**
- 三四线城市快速增长（电商红利）
- 一线城市偏好品质和进口品牌

### 1.2 用户分层画像

| 用户类型 | 占比 | 核心需求 | 技术能力 | 付费意愿 |
|----------|------|----------|----------|----------|
| 二次元/动漫爱好者 | ~35% | 动漫角色还原、IP联名 | 中 | 中 |
| 手工DIY爱好者 | ~25% | 创意表达、个性化设计 | 中高 | 中 |
| 亲子家庭 | ~15% | 简单安全、教育娱乐 | 低 | 低 |
| 礼物制作者 | ~12% | 照片转拼豆、人像定制 | 低 | 中高 |
| 线下体验店顾客 | ~8% | 快速出图、低门槛 | 低 | 已付费体验 |
| Cosplay/谷子经济 | ~5% | 精细还原、复杂图案 | 高 | 高 |

### 1.3 使用场景分布

**居家DIY场景（约70%）：**
- 个人兴趣爱好、解压放松
- 制作挂件、冰箱贴、钥匙扣等小物件
- 动漫角色、游戏角色制作
- 宠物照片、情侣照片定制

**线下体验店场景（约20%）：**
- 朋友聚会、情侣约会、亲子活动
- 按小时收费（约30元/小时），全天约90元
- 有人拼制结婚照、生日蛋糕等特殊场景
- 门店提供材料、工具和指导

**商业/创作场景（约10%）：**
- Etsy/淘宝等电商平台售卖成品
- 社交媒体内容创作（小红书、抖音）
- 手工博主教程制作
- 定制委托订单

### 1.4 新手 vs 进阶用户需求差异

| 维度 | 新手用户 | 进阶用户 |
|------|----------|----------|
| 图案复杂度 | 简单卡通、小图案（29x29以内） | 复杂角色、大型作品（多板拼接） |
| 颜色数量 | 越少越好（8-16色） | 可接受更多颜色（20-40色） |
| 核心诉求 | 不出错、能完成 | 精细还原、表达完整 |
| 工具偏好 | 一键生成、傻瓜式操作 | 可调参数多、手动编辑 |
| 信息需求 | 详细教程、色号清单 | 高效流程、精准控制 |
| 典型作品 | 钥匙扣、小挂件 | 多板大幅挂画、立体作品 |

## 2. 用户痛点汇总

### 2.1 转换质量痛点（核心痛点）

**1. 颜色识别不准确**
- AI生成的像素图包含几千种过渡色，而实际拼豆只有固定221色
- 自动配色容易堆出一堆相近但买不到的色
- RGB均值算法导致颜色偏移，深色和浅色像素一平均就变成灰不拉几的颜色

> "市面上多数拼豆教程建议用8色16色简化图片，但真正的问题不是颜色数量，而是颜色分布的语义保留" —— 用户反馈

**2. 灰色毛状边界线（黑边问题）**
- 传统软件用RGB均值算法，深浅像素一平均就变成灰色
- 生成的图纸边缘总有奇怪的黑边
- 这是拼豆转图中最常见、最影响美观的问题之一

> "传统软件用RGB均值算法，深浅像素一平均就变成灰不拉几的颜色。BeadPattern用主导色算法，取区域内出现最多的颜色，黑边问题直接消失。" —— 开源项目作者

**3. 杂色过多、颜色无法合并**
- 原图明明只有黑白肤色，结果生成后冒出几十种接近色
- 转换后出现很多孤立的杂散颜色（只在角落出现一两次）
- 没有进行颜色合并操作，导致画面碎成一片
- 无法自适应合并同色系的颜色

> "颜色识别不准确、灰色毛状边界线、无法自适应合并同色系的颜色、手动着色困难、无法给出采购清单、限制图片的导出和打印" —— 拼豆底稿生成器开发者总结的6大市场痛点

**4. 背景无法剥离**
- 正常的拼豆往往只拼主体形象
- 市面工具无法一步到位做到自动抠图去背
- 背景颜色统计拖累实际材料计算

**5. 人像转换效果差**
- 人脸糊了、颜色特别脏
- 颗粒感太重、拼出来不像原图
- 夜景照片和高细节风景图转换后特别乱

> "人脸糊了、颜色特别脏、拼出来不像原图、颗粒感太重、图纸根本看不懂" —— 用户真实反馈

### 2.2 使用体验痛点

**1. 操作复杂、学习成本高**
- 现有工具大多需要付费订阅、强制注册账号
- 手机端操作体验极差
- 设置项过多，让新手不知所措

> "其他perler bead pattern creators我试过的都太混乱了，设置太多。我喜欢能直接拖图片进去，得到图案，然后开始制作。" —— Leo, Cosplay Prop Maker

**2. 生成速度慢**
- 部分工具需要上传到服务器处理，等待时间长
- 大尺寸图片处理卡顿
- 实时调整参数时响应不流畅

**3. 图纸可读性差**
- 格子密密麻麻，根本看不懂
- 色号标注不清晰
- 没有坐标/网格辅助线，摆豆时难以定位

> "很多工具虽然能转，但最后格子密密麻麻根本看不懂" —— 用户反馈

**4. 隐私担忧**
- 用户不愿意上传个人照片到服务器
- 担心照片被保存或滥用
- 希望能本地处理保护隐私

### 2.3 制作流程痛点

**1. 手动数颜色耗时**
- 一个中等大小图案光数颜色就要半小时
- 不知道每种颜色要买多少颗
- 手动一颗颗去数是对"手工党的侮辱"

> "最烦的是做完设计还要手动数每种颜色要买多少颗，一个中等大小的图案光数颜色就要半小时" —— BeadPattern开发者

**2. 色号匹配困难**
- 不同品牌色号不统一（Perler、Hama、Artkal、MARD等）
- 自动生成的颜色超出手头豆子的范围
- 不知道自己的豆子库存对应什么色号

**3. 尺寸选择困难**
- 不清楚多大尺寸适合自己
- 容易犯的错误是生成一个永远不想制作的尺寸
- 大尺寸图案超出底板范围

**4. 材料采购不确定**
- 不知道需要买多少颗豆子
- 担心某种颜色不够、其他颜色买多浪费
- 希望有精确的材料清单

**5. 熨烫技术难题**
- 温度过高导致变形
- 拼豆排列错位
- 冷却前触碰成品导致损坏
- 大面积作品拼接困难

> "我们曾拼了一个美少女战士，用了3-4天，因为太大不敢用胶带法转移，结果豆子粘在熨烫纸上，一半熟了另一半散了，花了好多功夫重新拼" —— Reddit用户

## 4. 典型使用场景

### 场景1：动漫/游戏角色制作（占比约35%，最热门场景）

**用户特征：**
- 二次元爱好者、游戏玩家、Cosplay群体
- 希望还原自己喜欢的动漫角色、游戏角色
- 对还原度有一定要求，希望颜色准确、轮廓清晰

**常见需求：**
- 上传动漫截图或角色立绘，自动生成拼豆图纸
- 颜色数量适中（15-25色），保持角色特征
- 尺寸通常在 48x48 到 80x80 之间
- 制作成挂件、摆件或墙饰

**典型案例：**
- 宫崎骏动画角色（龙猫、千与千寻等）
- 迪士尼公主系列
- 宝可梦、原神、恋与制作人等游戏角色
- 名侦探柯南、美少女战士等经典动漫

**制作要点：**
- 线条清楚、颜色分明的原图效果更好
- 需要保留角色的关键特征（发型、眼睛、服装颜色）
- 边缘处理要干净利落

### 场景2：照片转人像/宠物拼豆（占比约20%，高情感价值）

**用户特征：**
- 希望制作个性化礼物（情侣礼物、生日礼物）
- 宠物主人想要纪念自己的宠物
- 粉丝想要制作偶像/爱豆照片

**常见需求：**
- 上传自拍、宠物照、情侣照，转成拼豆图纸
- 人脸轮廓要自然，不能糊成马赛克
- 颜色数量控制在20色以内，方便采购
- 通常做成挂件、相框摆件

**适合的照片类型：**
- 主体明确（单人头像、宠物）
- 颜色不要太杂
- 对比明显（深色背景、清晰轮廓）

**容易翻车的照片类型：**
- 大合照（人物太小，脸容易糊）
- 夜景照片（颜色太复杂，容易脏）
- 高细节风景（树叶、草地像素化后特别乱）

### 场景3：文字/LOGO制作（占比约10%，实用性强）

**用户特征：**
- 制作个性化装饰（HOME、WELCOME牌子）
- 生日礼物（朋友名字的拼豆作品）
- 店铺标识、节日装饰
- 表白礼物（I LOVE YOU等）

**常见需求：**
- 输入文字自动生成像素风格文字图案
- 支持中英文、数字和常用符号
- 可选择文字颜色和背景颜色
- 通常只需2-3种颜色，材料简单

**典型尺寸：**
- 英文HELLO：约29x29底板
- 中文：需要50珠以上宽度，建议不超过4个字

**应用场景：**
- 家居装饰牌
- 手机链、钥匙扣文字
- 节日主题挂饰
- 浪漫表白礼物

### 场景4：小挂件/钥匙扣制作（占比约25%，入门首选）

**用户特征：**
- 新手入门首选项目
- 希望快速完成、获得成就感
- 做成实用的小物件

**常见需求：**
- 小尺寸图案（不超过20颗豆子宽）
- 颜色少（最多3-4种颜色）
- 实心形状为主（心形、方形、简单动物）
- 避免细薄元素（只有一颗豆子宽会太脆弱）

**常见成品类型：**
- 钥匙扣/钥匙链
- 冰箱贴
- 手机挂件
- 发夹、鞋花

**制作要点：**
- 两面熨烫确保强度
- 避免过度熨烫成实心塑料片
- 可用小电钻打孔装钥匙环

### 场景5：大型多板作品（占比约5%，进阶挑战）

**用户特征：**
- 有丰富拼豆经验的进阶玩家
- 希望制作大幅挂画或复杂场景
- 愿意投入数天时间和大量材料

**常见需求：**
- 大尺寸图案（多个底板拼接）
- 需要分板导出打印功能
- 颜色数量可能达到30-50色
- 需要坐标/辅助线方便定位

**制作挑战：**
- 拼接对齐精度要求高
- 转移和熨烫风险大（大面积容易出问题）
- 材料成本高
- 耗时极长（3-7天）

### 场景6：亲子DIY/教育场景（占比约15%，稳定增长）

**用户特征：**
- 家长带孩子一起做手工
- 学校/教育机构手工课
- 希望有教育意义和娱乐价值

**常见需求：**
- 简单图案、大格子
- 颜色少、易于辨识
- 1:1图纸可直接垫在底板下照着拼
- 安全材料、操作简便

**典型活动：**
- 家庭手工活动
- 学校美术课
- 手工坊团建活动
- 节日主题手工（圣诞、春节等）

## 5. 用户期望的功能清单

### 基础功能（所有用户都需要）
- [x] 上传图片（JPG/PNG）自动转换为拼豆图纸
- [x] 支持多品牌色号匹配（MARD、Perler、Hama、Artkal、COCO等）
- [x] 可调整图案尺寸（10x10到100x100+）
- [x] 可限制最大颜色数量
- [x] 自动合并相近颜色、清理杂色
- [x] 背景自动识别和移除
- [x] 自动统计每种颜色用量（生成采购清单）
- [x] 导出PDF（可打印）和PNG（高清图片）
- [x] 带色号标注和网格线的图纸
- [x] 免费使用、无需注册登录
- [x] 本地处理（不上传服务器）
- [x] 实时预览生成效果

### 编辑功能（进阶用户需要）
- [x] 手动编辑：点击单个像素修改颜色
- [x] 画笔工具：自由绘制
- [x] 橡皮擦：擦除不需要的部分
- [x] 填充工具：一键填充区域
- [x] 吸管工具：吸取已有颜色
- [x] 颜色替换：批量替换特定颜色
- [x] 撤销/重做功能
- [x] 亮度/对比度/饱和度调整
- [x] 镜像翻转

### 增强功能（差异化卖点）
- [x] 像素文字生成器（中英文）
- [x] AI优化/AI生成图片
- [x] 抖动效果（平滑颜色过渡）
- [x] 大尺寸分板导出
- [x] 多图层支持
- [x] 模板素材库

## 6. 价格敏感度分析

### 用户对付费工具的态度

**免费偏好强烈：**
- 绝大多数用户首选免费工具
- "100%免费、无需登录"是重要卖点
- 开源工具（如perler-beads、七卡瓦）受欢迎程度高

**可接受的付费点：**
- 单次付费（约15元）比订阅制更容易接受
- 付费解锁高级功能（无水印、高精度、多图层）
- 线下体验店可按使用次数付费

**现有付费模式参考：**
- 西瓜拼豆生成器：15元中端定价，一键生成
- 高级版功能通常包含：无水印输出、高精度转换、多图层编辑、AI生成
- 大部分工具采用"免费基础版+付费高级版"模式

### 付费功能接受度排序

| 功能 | 付费接受度 | 说明 |
|------|------------|------|
| 基础转换功能 | 低 | 用户期望免费 |
| 无水印导出 | 中 | 可以接受少量付费 |
| AI生成/优化 | 中高 | 愿意为好效果付费 |
| 高级编辑功能 | 中 | 进阶用户愿意付费 |
| 云端保存 | 低 | 本地处理更受青睐 |

## 7. 差异化竞争的机会点

### 机会1：更好的颜色合并算法
- 当前大多数工具的杂色清理效果不理想
- 基于BFS连通区域检测+主导色算法的方案效果更好
- 解决"灰色毛边"这一最普遍的痛点

### 机会2：深度适配国内品牌色号
- 国内拼豆品牌色号体系与国外不同
- 支持MARD（249色）、COCO、漫漫、盼盼、咪小窝等品牌
- 自动匹配用户实际购买的豆子颜色

### 机会3：移动端优先体验
- 现有工具大多在PC端使用，但用户实际制作时需要在拼豆台边看手机
- 竖屏快速生成+桌面端精细编辑的双模式设计
- 触摸友好的交互设计

### 机会4：本地处理+隐私保护
- 用户不愿上传个人照片到服务器
- 基于Web Worker的浏览器本地处理方案
- 零服务器成本，纯前端实现

### 机会5：智能颜色数量推荐
- 根据图片内容自动推荐合适的颜色数量
- 而不是让用户自己摸索
- 新手模式（8-16色）和进阶模式（20-40色）智能切换

### 机会6：一站式从设计到采购
- 不仅生成图纸，还直接生成精确采购清单
- 对接电商平台，一键购买所需材料
- 打通"设计-采购-制作"全链路

### 机会7：线下体验店专用版
- 为手作店提供商用工具
- 支持快速批量出图
- 会员管理、作品存档等功能

### 机会8：社区+模板生态
- 热门IP模板库（宫崎骏、迪士尼、宝可梦等）
- 用户分享和收藏功能
- 降低新手找图纸的难度

## 9. 调研结论与产品建议

### 核心结论

1. **拼豆市场正在快速增长**：2025年电商平台销售额2.91亿元，同比增长近9倍，预计2026年接近10亿元。这是一个蓝海市场。

2. **用户对现有工具不满意**：颜色不准、杂色多、操作复杂、需要注册付费是主要痛点。市场上还没有一个"完美"的解决方案。

3. **免费+本地处理是入场门槛**：用户强烈偏好免费工具，且不愿上传照片。纯前端实现可以零服务器成本运营。

4. **颜色处理是核心技术壁垒**：谁能解决"灰色毛边+杂色清理+准确色号匹配"三大问题，谁就能赢得用户。

5. **移动端体验是差异化关键**：制作时用户需要在拼豆台边看手机，移动端友好的体验至关重要。

### 产品方向建议

1. **第一阶段（MVP）**：聚焦核心转换功能——准确色号匹配+自动颜色合并+背景移除+材料统计+PDF/PNG导出，免费使用、本地处理。

2. **第二阶段**：增加手动编辑工具（画笔、橡皮擦、颜色替换）+ 移动端优化 + 像素文字生成。

3. **第三阶段**：增加AI优化 + 模板库 + 社区分享 + 高级付费功能（无水印、多图层等）。

4. **长期**：打通材料采购链路，为线下体验店提供商用版，构建拼豆生态。
